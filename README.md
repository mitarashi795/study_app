# 勉強きろく

勉強した項目を「答えを見ずにこたえられた / 考え方は合ってたが間違えた / 答えられなかった」の3段階で評価し、
フォルダ(階層構造)・評価・キーワードで絞り込めるWebアプリです。評価の履歴と、日ごとの正答率グラフ付き。

- 番号の範囲を一括記録: 入力欄に `1-20` や `1-5,8,10` と書いて評価を選び「記録」
- 左のフォルダツリーで自由に階層化(追加・名前変更・削除・移動、ドラッグ&ドロップ対応)
- ビルド不要(HTML / CSS / JavaScript のみ)。データはブラウザの localStorage に保存(「バックアップ」でJSON書き出し可)

## GitHub Pages で公開する手順
1. 公開(Public)のリポジトリを作成
2. index.html, style.css, app.js, README.md をリポジトリ直下に置いて push
3. Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます
